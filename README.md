# vladchess-site

Сайт-визитка Владислава Дмитровского, шахматного тренера, метод ScienceChess.

Один статический файл `index.html`, весь CSS и JS внутри него. Картинки — в
`images/`. Ни фреймворков, ни сборки, ни npm: страница открывается двойным
кликом и деплоится простым копированием файлов.

## Структура

```
index.html      — вся страница: разметка, стили, скрипт
images/         — фотография, скриншоты отзывов, диаграмма задачи, иконка Lichess
.nojekyll       — отключает обработку Jekyll на GitHub Pages (файлы отдаются как есть)
```

Все пути к картинкам в `index.html` относительные (`images/...`, без ведущего
слэша). Это осознанный выбор: без него сайт сломался бы под путём вида
`username.github.io/vladchess-site/`, где GitHub Pages отдает проектный сайт
до подключения домена (см. ниже).

## Публикация на GitHub Pages

1. **Settings → Pages** в этом репозитории.
2. **Source**: Deploy from a branch.
3. **Branch**: `main`, папка `/ (root)`.
4. **Save**.

Через минуту сайт будет доступен по адресу
`https://6c79fv6sdh-wq.github.io/vladchess-site/`. Дальше любой пуш в `main`
обновляет сайт автоматически, без дополнительных действий.

## Подключение своего домена

Домен пока не куплен, поэтому здесь нет файла `CNAME` — его появление и есть
единственный недостающий шаг. Когда домен куплен:

1. В **Settings → Pages → Custom domain** впишите домен (например
   `sciencechess.ru`, без `https://` и без слэша на конце). GitHub сам создаст
   файл `CNAME` в репозитории — коммитить его вручную не нужно.
2. У регистратора домена, в настройках DNS, добавьте записи:
   - для корневого домена (`sciencechess.ru`) — четыре A-записи на IP GitHub Pages:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - если нужен ещё и `www.sciencechess.ru` — CNAME-запись на
     `6c79fv6sdh-wq.github.io`.
3. DNS применяется не мгновенно — от нескольких минут до суток.
4. Как только GitHub подтвердит домен, в **Settings → Pages** появится
   галочка **Enforce HTTPS** — включите её: сертификат SSL выпускается
   автоматически и бесплатно.

## Добавление раздела /lab/ (Chess Lab)

Задумано заранее, поэтому переделка архитектуры не потребуется:

- Chess Lab будет жить в отдельной папке `lab/` в корне репозитория —
  собственный `index.html`, собственные картинки внутри `lab/`, ничего общего
  с файлами корня сайта не используется и не задевается.
- Так как сайт статический и без сборки, папка `lab/` на GitHub Pages
  автоматически становится разделом `/lab/` — никакой отдельной настройки
  хостинга не нужно.
- Когда раздел будет готов к публикации, останется добавить на него ссылку
  из шапки сайта (`<nav>` в `index.html`) — это единственное место в корневой
  странице, которое вообще будет знать о существовании `/lab/`.
- До этого момента папку `lab/` в репозиторий сознательно не кладем: страница-заглушка
  была бы доступна по прямой ссылке уже сейчас, а раздела ещё нет.

## Локальный просмотр

Открыть `index.html` двойным кликом — работает офлайн, без сервера.
